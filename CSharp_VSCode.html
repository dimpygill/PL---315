C# in Visual Studio Code

A Step-by-Step Beginner Tutorial

Goal: In this tutorial, you will create your first C# console project in Visual Studio Code, examine the Program.cs file, and run the program using the .NET command-line tools.

1Open Visual Studio Code

Start Visual Studio Code (VS Code). Then open the integrated terminal:

Terminal → New Terminal

The terminal appears near the bottom of the VS Code window. We will use it to create and run our C# project.

2Check That the .NET SDK Is Installed

In the VS Code terminal, type:

dotnet --version

Press Enter. If the .NET SDK is installed correctly, you will see a version number. Your version number may be different from another student's version.

10.0.100
Important: A C# extension in VS Code does not replace the .NET SDK. If the terminal says that dotnet is not recognized or cannot be found, the .NET SDK needs to be installed or configured correctly.

3Open a Folder for Your Work

Create or choose a folder where you want to keep your class projects. For example:

CSharpPractice

In VS Code, choose File → Open Folder and open that folder.

4Create Your First C# Console Project

In the VS Code terminal, type:

dotnet new console -n HelloCSharp

This tells .NET to create a new console application named HelloCSharp.

Next, move into the new project folder:

cd HelloCSharp

The project will contain files such as:

HelloCSharp/
├── Program.cs
└── HelloCSharp.csproj
FilePurpose
Program.csContains the C# source code that we will write.
HelloCSharp.csprojThe C# project file. It contains project information used by .NET to build and run the application.
C# file extension: C# source-code files use the .cs extension.

5Open Program.cs

In the VS Code Explorer on the left, click Program.cs.

Replace its contents with the following first program:

Console.WriteLine("Hello, World!");

string name = "Alex";
int age = 20;

Console.WriteLine("Name: " + name);
Console.WriteLine("Age: " + age);

int x = 10;
int y = 5;
int sum = x + y;

Console.WriteLine("Sum: " + sum);

Save the file using Ctrl + S.

6Where Is Main()?

You may notice that this program does not explicitly contain a Main() method or a Program class.

Older or more explicit C# code may look like this:

using System;

class Program
{
    static void Main(string[] args)
    {
        Console.WriteLine("Hello, World!");
    }
}

Modern C# supports top-level statements. Therefore, for a simple program we can write:

Console.WriteLine("Hello, World!");
Programming Language Design Concept: The program still has an entry point. With top-level statements, however, you do not have to explicitly write the Main() method. The compiler handles the entry-point structure for you.

7Run the Program

Make sure the terminal is currently inside the HelloCSharp project folder. Then type:

dotnet run

Press Enter. You should see output similar to:

Hello, World!
Name: Alex
Age: 20
Sum: 15

8Modify and Run Again

Change the value stored in name:

string name = "Maria";

Save the file and run the program again:

dotnet run

You should now see Name: Maria in the output.

Write Code → Save → Run → Observe Output → Modify → Run Again

9Understand the Basic C# Syntax

Consider this statement:

string name = "Alex";
PartMeaning
stringThe data type.
nameThe variable name.
=The assignment operator.
"Alex"The value being stored.

To display output in a console program, we can use:

Console.WriteLine("Hello!");

10Compare C, C#, and Python

All three languages can perform the same basic task, but their syntax and design choices differ.

C

#include <stdio.h>

int main()
{
    printf("Hello, World!\n");
    return 0;
}

C# — Modern Top-Level Statements

Console.WriteLine("Hello, World!");

Python

print("Hello, World!")
LanguageSource ExtensionEntry-Point Observation
C.cAn explicit main() function is used as the program entry point.
C#.csModern C# can use top-level statements, so an explicit Main() does not have to be written.
Python.pyTop-level statements in the module are executed; a main() function is not required.
