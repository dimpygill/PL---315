Solution: Identify and Classify Tokens

CSBS 315 · Syntax, Tokens & Grammars · C, C#, and Python
The token streams below are pedagogical representations appropriate for this activity. In Python, logical NEWLINE, INDENT, and DEDENT are shown because they carry syntactic structure.

Why INDENT and DEDENT? Python uses indentation as part of its block syntax. The tokenizer therefore emits INDENT when an indented block begins and DEDENT when that block ends. In the equivalent C and C# examples, braces { and } explicitly delimit the blocks.

Final discussion: The programs express approximately the same computation, but their token streams differ because the languages make different lexical and syntactic design choices. C and C# use explicit punctuation such as ;, {, and }. Python uses logical NEWLINE plus INDENT/DEDENT to represent some of that structure.
