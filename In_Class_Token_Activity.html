Token Categories

Use the following categories. For this activity, numeric and string values are grouped under the general category LITERAL.

CategoryMeaningExamples
KEYWORDReserved word with a special meaning in the language.int, if, return
IDENTIFIERName used for a variable, function, method, class, etc.age, main, printf
LITERALA value written directly in source code.20, 18, "Adult"
OPERATORPerforms assignment, arithmetic, comparison, or another operation.=, +, >=
PUNCTUATION / DELIMITERSeparates or structures parts of the program.( ) { } ; , . :
NEWLINEIn Python, a logical newline can terminate a simple statement.NEWLINE
INDENTPython token marking the beginning of an indented block.INDENT
DEDENTPython token marking the end of an indented block.DEDENT
