Concept Guide — Everything You Need for This Activity

Non-terminal: A non-terminal is a grammar category that describes the role or structure of source code. It is not something the programmer literally types as part of the program. In this activity, non-terminals are written inside angle brackets, such as <program>, <statement>, <declaration>, <identifier>, and <number>.

Terminal: A terminal is an actual token/token kind that appears at the leaves of the grammar. Examples include keywords and symbols such as int, return, =, ;, (, and Python's logical NEWLINE.

Think of the relationship this way:

<declaration>                    ← non-terminal: name of a structure
      ↓
int <identifier> = <number> ;    ← grammar description
      ↓
int age = 20;                    ← actual source code

Here, <declaration>, <identifier>, and <number> are non-terminals. The source code int age = 20; is the concrete code that matches that structure.

Most specific non-terminal: When asked for the most specific non-terminal, choose the category that describes that exact piece of code—not a broader category that also contains it. For example, int age = 20; may ultimately be part of a <statement> and a <program>, but <declaration> is the most specific choice for that line.

Grammar hierarchy: Non-terminals can contain other non-terminals. A simplified hierarchy may look like:

<program>
    ↓
<statement-list>
    ↓
<statement>
    ↓
<declaration>
    ↓
int age = 20;

Python reminder: NEWLINE, INDENT, and DEDENT are structural tokens/terminals when they are relevant to the grammar. They are not non-terminals.

Common Non-Terminal Categories Used in This Activity

The names below describe different kinds of program structure. These are the simplified non-terminal categories you will use in this activity.

Non-terminal categoryWhat it representsExample from source code
<program>The entire program being described.age = 20
print(age) together
<statement-list>A sequence of statements. In our simplified grammar, it can contain one statement or several statements.age = 20
print(age)
<statement>One complete instruction or statement.age = 20
<declaration>A declaration that introduces a variable/type in the simplified C or C# examples.int age = 20;
<assignment>An assignment that gives a value to a name.age = 20
<function-call>A call to a function.printf("%d", age); or print(age)
<method-call>A call to a method in the simplified C# example.Console.WriteLine(age);
<return-statement>A statement that returns control/value from a function.return 0;
<main-function>The complete main function, including its body, in our simplified C example.int main() { ... }
<identifier>A grammar category for a name.age, print
<number>A grammar category representing a numeric value in this simplified grammar.20, 0
<if-statement>An if construct containing a condition and a body.if age >= 18: ...
Important about <statement-list>: A statement list means a sequence of statements. It does not require many statements. For example, in: 
if age >= 18:
    print("Adult")
the body of the if contains one statement, so in our simplified teaching grammar it can still be represented as a <statement-list> containing one <statement>. If another line were added to the same indented block, the same statement list would contain two statements.

Quick Example

int age = 20;

A simplified grammar can describe this source statement as:

<declaration> ::= int <identifier> = <number> ;

Here, <declaration>, <identifier>, and <number> are non-terminals. The concrete source is ultimately built from terminals/tokens such as int, an identifier token with lexeme age, =, a numeric literal 20, and ;.

Important: The grammars in this activity are intentionally simplified teaching grammars. They are designed to help you recognize grammatical structure; they are not the complete official grammars of C, C#, or Python.
