1. What is Mutability?

An object is mutable if its internal state or value can be modified after it is created without changing its memory address. An object is immutable if its value cannot be changed once created; any modification results in a brand-new object allocation.

Language Immutable Types Mutable Types
Python int, float, str, tuple, bool list, dict, set
C String literals (`const char*`) Arrays (`char arr[]`), heap allocations (`malloc`)
C# string, readonly struct, record Classes, arrays, int, struct, StringBuilder, List<T>

3. Sandbox 2: C Pointer Mutability & Const

In C, pointers allow direct memory control. You can use const to make memory read-only or omit it for full read-write mutability — and you can mix both inside the same struct or scope.

5. Sandbox 4: C# Classes — Mutable vs Immutable Members

A C# class is mutable by default. But you can mix mutable and immutable members inside the same class using get; set;, get; (readonly), get; init;, and readonly fields. The string reference can be mutable even though the string content is always immutable.
