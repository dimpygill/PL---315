Before You Start

What You Are Installing and Why

To write and run programs in C, C#, and Python, you need two things for each language: a compiler or interpreter (the software that actually runs your code) and an editor (where you write it). This guide sets up all three languages and one editor — Visual Studio Code — that works well for all of them.

LanguageWhat runs your codeWhat you installApproximate size
Python CPython interpreter Python 3 (from python.org) ~30 MB
C GCC compiler GCC via MinGW (Windows) / Xcode Tools (Mac) / apt (Linux) ~200–500 MB
C# .NET Runtime + C# compiler (Roslyn) .NET SDK (from microsoft.com) ~200 MB
Editor — Visual Studio Code (from code.visualstudio.com) ~80 MB

Recommended order: Install VS Code first, then Python, then C (GCC), then C# (.NET SDK). Follow the steps for your operating system throughout each section.

Section 1

Installing Visual Studio Code

Visual Studio Code (VS Code) is a free, lightweight code editor made by Microsoft. It works on Windows, macOS, and Linux and supports all three languages through extensions. Install it first — before any language tools.

VS Code vs Visual Studio: These are two different programs. Visual Studio Code (what we install here) is a lightweight editor. Visual Studio is a full IDE that is Windows-only and much larger. Make sure you download VS Code, not Visual Studio.

1
Windows  Download VS Code
Go to code.visualstudio.com and click the big blue "Download for Windows" button. This downloads a .exe installer file (about 80 MB).
2
Windows  Run the installer
Double-click the downloaded VSCodeSetup-x64.exe file. Accept the license agreement. On the "Select Additional Tasks" screen, check all four boxes — especially "Add to PATH" and "Open with Code". Click Install.

Tip: Checking "Add to PATH" lets you type code . in any terminal to open VS Code in the current folder. This is very useful throughout the course.

3
Windows  Launch VS Code
Click Finish with "Launch VS Code" checked, or find it in the Start menu. VS Code should open showing a Welcome tab. If it opens, this step is complete.
1
macOS  Download VS Code
Go to code.visualstudio.com and click "Download for Mac". This downloads a .zip file. Double-click it to extract Visual Studio Code.app.
2
macOS  Move to Applications
Drag Visual Studio Code.app into your Applications folder. Then open it from Applications or Spotlight (⌘ Space → type "code").
3
macOS  Add "code" command to Terminal
Inside VS Code, press ⌘ Shift P to open the Command Palette. Type "shell command" and select "Shell Command: Install 'code' command in PATH". Enter your password if prompted. Now you can type code . in any Terminal window.
1
Linux  Install via package manager (recommended)
Open a terminal and run the commands below. This adds Microsoft's repository and installs VS Code through your package manager, making future updates automatic.
Terminal — Ubuntu / Debian
sudo apt update
sudo apt install wget gpg

wget -qO- https://packages.microsoft.com/keys/microsoft.asc \
  | gpg --dearmor > packages.microsoft.gpg

sudo install -D -o root -g root -m 644 packages.microsoft.gpg \
  /etc/apt/keyrings/packages.microsoft.gpg

echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/packages.microsoft.gpg] \
  https://packages.microsoft.com/repos/code stable main" \
  | sudo tee /etc/apt/sources.list.d/vscode.list

sudo apt update
sudo apt install code

For Fedora / RHEL: visit code.visualstudio.com and download the .rpm file, then run sudo rpm -i code-*.rpm. For Arch Linux: use yay -S visual-studio-code-bin.

2
Linux  Launch VS Code
Type code in the terminal, or find it in your applications menu. The Welcome tab should open.
✓ Verify VS Code installed correctly

Open a terminal (or Command Prompt on Windows) and run:

code --version

You should see a version number like 1.90.0. If you see "command not found," reopen your terminal and try again — the PATH update takes effect in new terminal sessions.

Section 2

Installing Python 3

🐍
Python 3
Install the latest Python 3 release. Python 2 is end-of-life — always install Python 3.
1
Windows  Download Python
Go to python.org/downloads. The site detects Windows and shows the latest Python 3 release. Click the big yellow "Download Python 3.x.x" button.
2
Windows  Run the installer — critical checkbox
Double-click the downloaded .exe file. Before clicking Install Now, check the box that says "Add Python to PATH" at the bottom of the first screen. This is the most common mistake — if you skip it, Python will not work in the terminal.

⚠ Critical: The "Add Python to PATH" checkbox is unchecked by default. If you miss it, you will need to uninstall and reinstall Python, or manually add it to PATH. Always check this box.

After checking the box, click "Install Now". The installation takes about 1–2 minutes.

3
Windows  Verify in Command Prompt
Open a new Command Prompt window (Start → type "cmd" → Enter). Run the verification command below.
Command Prompt
python --version

If you see Python 3.x.x — you're done. If you see Python 2.x or "not recognised," try python3 --version. On some Windows machines, use py --version.

1
macOS  Check if Python 3 is already installed
Open Terminal (Applications → Utilities → Terminal, or ⌘ Space → "terminal"). Run:
Terminal
python3 --version

If you see Python 3.x.x, Python is already installed — skip to Section 3. If you see an error or Python 2.x, continue to the next step.

2
macOS  Install via python.org (recommended)
Go to python.org/downloads, download the macOS .pkg installer, and run it. Click through the installer screens (defaults are fine). Python will install to /usr/local/bin/python3.

Alternative — Homebrew: If you use Homebrew, run brew install python3. Either method works for this course.

1
Linux  Install Python 3
Python 3 is usually pre-installed on Linux. Check first, then install if needed:
Terminal — Ubuntu / Debian
python3 --version               # check if already installed
sudo apt update
sudo apt install python3 python3-pip python3-venv
Terminal — Fedora
sudo dnf install python3 python3-pip
✓ Verify Python installation
python3 --version        # macOS / Linux
python --version         # Windows (or py --version)

Expected output: Python 3.11.x or higher. Also verify pip (Python's package manager):

pip3 --version           # macOS / Linux
pip --version            # Windows
Section 3

Installing GCC — the C Compiler

⚙️
C / GCC
GCC (GNU Compiler Collection) is the standard C compiler. Installation varies most across operating systems.

What GCC does: GCC takes your .c source file and compiles it into an executable your computer can run directly. Unlike Python (interpreted) or C# (JIT compiled), C produces a standalone binary — no runtime needed to distribute it.

Windows  Installing GCC via MSYS2

Windows does not include a C compiler. We install one via MSYS2 — a package manager that provides GCC and other Unix tools for Windows.

1
Download and install MSYS2
Go to msys2.org and download the installer (msys2-x86_64-YYYYMMDD.exe). Run it. Install to the default location C:\msys64. Click through the installer — defaults are correct.
2
Open the MSYS2 terminal and update packages
After installation, the MSYS2 terminal opens automatically. Run the update command. When it finishes and asks you to close the window, do so — then reopen MSYS2 from the Start menu and run the update again.
MSYS2 terminal
pacman -Syu
3
Install GCC
In the MSYS2 terminal, install the GCC toolchain:
MSYS2 terminal
pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain

When asked "Enter a selection," press Enter to install everything. This downloads and installs GCC, G++, GDB (debugger), and related tools.

4
Add GCC to Windows PATH
GCC installs to C:\msys64\ucrt64\bin. You need to add this folder to your Windows PATH so that Command Prompt and VS Code can find it.
  1. Press Windows key, type "environment variables", click "Edit the system environment variables"
  2. Click "Environment Variables…" button at the bottom
  3. Under "System variables", find Path and click Edit
  4. Click New and type: C:\msys64\ucrt64\bin
  5. Click OK on all three windows
  6. Open a new Command Prompt (existing ones won't see the change)

Important: Always open a new Command Prompt after changing PATH. Existing windows won't see the update.

macOS  Installing GCC via Xcode Command Line Tools

1
Install Xcode Command Line Tools
Open Terminal and run the command below. A dialog box will appear — click Install (not "Get Xcode"). This installs Apple's version of GCC/Clang and other development tools (~700 MB). It may take 5–15 minutes.
Terminal
xcode-select --install

Note: macOS installs Clang (Apple's compiler) which is fully compatible with GCC for this course. When you run gcc on macOS, it actually runs Clang — this is fine. All C code in CSBS 315 compiles with either.

Linux  Installing GCC

1
Install the build-essential package
This installs GCC, G++, make, and other essential build tools in one command:
Terminal — Ubuntu / Debian
sudo apt update
sudo apt install build-essential gdb
Terminal — Fedora
sudo dnf groupinstall "Development Tools"
sudo dnf install gdb
✓ Verify GCC installation
gcc --version

Expected output: something like gcc (GCC) 13.x.x or on macOS Apple clang version 15.x.x. Both are correct. If this command is not found, reopen your terminal and try again.

Section 4

Installing the .NET SDK for C#

◈
C# / .NET SDK
The .NET SDK includes the C# compiler, the .NET runtime, and the dotnet command-line tool. Install the latest LTS (Long-Term Support) version.
1
Download the .NET SDK
Go to dotnet.microsoft.com/download. Download the .NET SDK (not the Runtime — the SDK includes everything). Choose the latest LTS version (look for the "Long Term Support" label). Select your operating system.

SDK vs Runtime: The SDK includes the compiler and tools needed to write and build programs. The Runtime only runs already-compiled programs. Always install the SDK for development.

2
Windows  Run the .NET installer
Run the downloaded .exe file. Click through the installer — all defaults are correct. The installer automatically adds dotnet to your PATH. No extra steps needed.
2
macOS  Run the .NET installer
Run the downloaded .pkg file. Click through the installer. Open a new Terminal window after installation completes.

Apple Silicon (M1/M2/M3): Download the Arm64 version of the .NET SDK, not x64. The download page should auto-detect this — look for "macOS Arm64" in the download options if it doesn't.

2
Linux  Install .NET via package manager
Microsoft provides packages for most Linux distributions. Run the commands below for Ubuntu/Debian:
Terminal — Ubuntu 22.04 / Debian 12
sudo apt update
sudo apt install -y dotnet-sdk-8.0
Terminal — Fedora
sudo dnf install dotnet-sdk-8.0

If the package is not found, visit learn.microsoft.com/dotnet/core/install/linux for your specific distribution's instructions.

✓ Verify .NET SDK installation
dotnet --version

Expected output: 8.0.x (or whichever LTS version you installed). Also run:

dotnet --list-sdks

This lists all installed .NET SDK versions. You should see at least one entry.

VS Code Extensions

VS Code is a general-purpose editor. Language-specific features — syntax highlighting, IntelliSense, debugging, running code — come from extensions. Install these three now.

How to install an extension: In VS Code, click the Extensions icon in the left sidebar (it looks like four squares), or press Ctrl+Shift+X (Windows/Linux) or ⌘Shift+X (macOS). Search for the extension name and click Install.

Configuring the Python interpreter in VS Code

After installing the Python extension, you need to tell VS Code which Python installation to use:

1
Open the Command Palette
Press Ctrl+Shift+P (Windows/Linux) or ⌘Shift+P (macOS). Type "Python: Select Interpreter" and press Enter.
2
Select your Python 3 installation
VS Code shows a list of Python installations it found. Select the one showing Python 3.x (not 2.x). On Windows it will show a path like C:\Users\YourName\AppData\Local\Programs\Python\Python3x\python.exe.

The selected interpreter appears in the bottom status bar of VS Code. You can click it at any time to switch interpreters.

Section 7

Your First Programs — Hello World in All Three Languages

The best way to confirm everything works is to write, compile/interpret, and run a program in each language. Follow these steps for each one.

🐍
Python — Hello World
No compilation step needed — Python runs directly.
1
Create a new file in VS Code
Open VS Code. Click File → New File. Save it as hello.py (the .py extension tells VS Code this is Python).
2
Write the program
hello.py
print("Hello, World!")
print("Python is working correctly.")
3
Run the program
Method 1 (VS Code): Click the ▶ Run button in the top-right corner of the editor.
Method 2 (terminal): Open the VS Code terminal (Ctrl+` or View → Terminal) and run:
Terminal
python3 hello.py     # macOS / Linux
python hello.py      # Windows
✓ Expected output
Hello, World!
Python is working correctly.
⚙️
C — Hello World
C requires a compile step before running. Two commands: compile, then execute.
1
Create hello.c in VS Code
Create a new file, save it as hello.c. Write the program below exactly — every character matters in C.
hello.c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    printf("C is working correctly.\n");
    return 0;
}
2
Compile and run from the terminal
Open the VS Code terminal (Ctrl+`). Navigate to the folder where you saved hello.c, then compile and run:
Terminal — compile then run
gcc hello.c -o hello    # compile: creates an executable named "hello"
./hello                 # run it (macOS / Linux)
hello.exe               # run it (Windows)

What -o hello means: The -o flag tells GCC what to name the output file. Without it, GCC creates a file named a.out (or a.exe on Windows). Naming it something meaningful is good practice.

✓ Expected output
Hello, World!
C is working correctly.
◈
C# — Hello World
C# uses the dotnet CLI to create, build, and run projects. Always work inside a project folder.
1
Create a new C# console project
Open the VS Code terminal. Navigate to a folder where you want to store your C# code. Run the command below — it creates a new folder called HelloCSharp with a working C# console project inside.
Terminal
dotnet new console -n HelloCSharp
cd HelloCSharp

This creates a folder with Program.cs (the C# source file), a .csproj project file, and an obj/ folder. Open the folder in VS Code: code .

2
Edit Program.cs
Open Program.cs in VS Code. It may already contain a Hello World. Replace the contents with:
Program.cs
Console.WriteLine("Hello, World!");
Console.WriteLine("C# is working correctly.");

Modern C# (top-level statements): Since .NET 6, you don't need a class or Main method for simple programs. The two lines above are a complete, valid C# program. We will cover what this means in Chapter 6.

3
Build and run
In the terminal (inside the HelloCSharp folder), run:
Terminal
dotnet run

dotnet run compiles and runs the project in one step. You can also separate them: dotnet build then dotnet run.

✓ Expected output
Hello, World!
C# is working correctly.

All three working? You are fully set up. Every program in this course can be written and run using exactly this workflow — create the file (or project for C#), write the code, compile if needed, and run.

Section 8

Troubleshooting Common Problems

Click any problem below to expand the solution.

"python is not recognised as an internal or external command" ▼

Cause: Python was installed without checking "Add to PATH," or the terminal was opened before Python was installed.

Fix (Windows):

  1. Try py --version instead — the Python Launcher may still work
  2. If that fails, uninstall Python from Settings → Apps, then reinstall and check "Add to PATH"
  3. Always open a new terminal after installing

Fix (macOS/Linux): Use python3 instead of python — on Unix systems Python 3 is usually accessed as python3.

"gcc is not recognised" or "gcc: command not found" ▼

Windows: The MSYS2 bin folder was not added to PATH, or you need to open a new terminal. Check that C:\msys64\ucrt64\bin is in your System PATH (see Section 3, Step 4). Open a new Command Prompt and try again.

macOS: Run xcode-select --install again. If it says "already installed," try clang --version instead of gcc --version — on macOS, gcc is an alias for Clang and sometimes the alias isn't set up. Both work fine.

Linux: Run sudo apt install build-essential again and check for errors. Try which gcc to see if it's installed but not on PATH.

"dotnet is not recognised" / dotnet command not found ▼

The .NET SDK installer should add dotnet to your PATH automatically. If it didn't:

Windows: Open a new Command Prompt (not the one you had open during installation). The PATH update only applies to new terminal sessions.

macOS/Linux: Run echo $PATH and check if /usr/local/share/dotnet or ~/.dotnet appears. If not, add it manually to your shell profile (~/.zshrc on macOS, ~/.bashrc on Linux):

export PATH=$PATH:$HOME/.dotnet
export PATH=$PATH:/usr/local/share/dotnet

Then run source ~/.zshrc (or source ~/.bashrc) and try again.

VS Code does not show Python as an available interpreter ▼

The Python extension may not have found your Python installation. Try these steps:

  1. Open the Command Palette (Ctrl+Shift+P) → type "Python: Select Interpreter"
  2. Click "Enter interpreter path…" at the bottom of the list
  3. Browse to your Python executable:
    Windows: C:\Users\YourName\AppData\Local\Programs\Python\Python3x\python.exe
    macOS: /usr/local/bin/python3
    Linux: /usr/bin/python3
  4. Click Select Interpreter
C program compiles but the output window disappears immediately ▼

This happens when you run the compiled program by double-clicking the .exe file — the console window opens, shows output, and immediately closes.

Fix: Always run C programs from the terminal (VS Code terminal, Command Prompt, or Terminal), not by double-clicking. In the terminal the output stays visible after the program finishes.

gcc hello.c -o hello
./hello              # macOS/Linux
.\hello.exe          # Windows PowerShell
hello.exe            # Windows Command Prompt
Python IndentationError when running a file ▼

Cause: Python uses indentation to define code structure. Mixing tabs and spaces causes an IndentationError, even if the code looks correct visually.

Fix: In VS Code, go to View → Command Palette → "Convert Indentation to Spaces". Set your tab size to 4 (bottom-right corner of VS Code shows "Spaces: 4"). Never mix tabs and spaces in Python files.

To prevent this in future: in VS Code settings, search for "editor.insertSpaces" and set it to true, and "editor.tabSize" to 4.

C# error: "The project file is not in the current directory" ▼

dotnet run must be run from inside the folder that contains the .csproj file — not from a parent folder, and not from the obj or bin subfolder.

cd HelloCSharp        # navigate INTO the project folder
ls                    # you should see HelloCSharp.csproj and Program.cs
dotnet run            # now run
On macOS: "xcrun: error: invalid active developer path" when running gcc ▼

This means Xcode Command Line Tools need to be (re)installed, usually after a macOS update.

xcode-select --install

If that shows "already installed," reset the path first:

sudo xcode-select --reset
xcode-select --install

Still stuck? Copy the exact error message from your terminal and search for it online. Stack Overflow, the official VS Code documentation at code.visualstudio.com/docs, and the .NET documentation at learn.microsoft.com cover almost every installation problem. Include your operating system and version in your search for best results.
