Assignment Solution: One Problem, Four Languages

Course: Programming Language Design (PL-315)

The expected updated salary for an original salary of $6,000 is $6,600 (salary × 1.10).

Part 1: Working Function Examples

C

#include <stdio.h>

double addBonus(double salary) {
    return salary * 1.10;
}

int main(void) {
    double result = addBonus(6000);
    printf("%.2f\n", result);
    return 0;
}

Output: 6600.00. C requires explicit parameter and return types. The function is called from main.

C#

using System;

class Program {
    static double AddBonus(double salary) {
        return salary * 1.10;
    }

    static void Main() {
        double result = AddBonus(6000);
        Console.WriteLine(result.ToString("F2"));
    }
}

Output: 6600.00. C# is statically typed; this example uses a static method defined in a class.

Python

def add_bonus(salary):
    return salary * 1.10

result = add_bonus(6000)
print(f"{result:.2f}")

Output: 6600.00. Python does not require type declarations. Formatting to two decimal places avoids displaying floating-point artifacts.

Microsoft SQL Server

CREATE FUNCTION dbo.AddBonus
(
    @Salary DECIMAL(12,2)
)
RETURNS DECIMAL(12,2)
AS
BEGIN
    RETURN @Salary * 1.10;
END;
GO

SELECT dbo.AddBonus(6000) AS NewSalary;

Output: 6600.00. A scalar SQL function declares parameter and return types and can be invoked in SELECT expressions.

C and C# check many type constraints at compile time. Python's runtime checks allow a function to accept different kinds of values, though unsupported operations can fail at runtime. SQL Server scalar functions use declared SQL types and can be evaluated as part of queries. SQL's set-based approach describes the desired result rather than explicitly looping over each row.

Part 3: 10,000 Employees

An application in C, C#, or Python could retrieve salaries from the database, loop through the records, and call the bonus function for each salary. For example:

def add_bonus(salary):
    return salary * 1.10

salaries = [5000, 6000, 7000]
for salary in salaries:
    print(f"{add_bonus(salary):.2f}")

Output: 5500.00, 6600.00, 7700.00 (one per line).

When salaries already reside in SQL Server, a single set-based query can calculate bonuses:

SELECT EmployeeID, Salary,
       Salary * 1.10 AS NewSalary
FROM Employees;

Alternatively, the previously defined scalar function can be used:

SELECT EmployeeID, Salary,
       dbo.AddBonus(Salary) AS NewSalary
FROM Employees;

Recommended approach: For this simple calculation, a direct SQL expression is generally preferable because it avoids transferring 10,000 records to application code solely for arithmetic. Scalar UDF performance can depend on the execution plan and whether SQL Server can inline the function. Application code remains appropriate when additional business logic or integration is required. The SELECT statements calculate displayed results; they do not permanently update stored salaries.

Part 4: Sample Discussion Responses

Do explicit types improve readability?

Explicit types make function contracts clear and help catch many errors before execution. Python provides concise, flexible definitions, and optional type hints can improve documentation and tooling without making Python statically typed by default.

How is SQL function calling different?

A SQL scalar function can appear in a SELECT expression evaluated for rows returned by a query. Unlike an explicit application loop, the SQL query specifies the desired set of results and lets the database engine choose an execution strategy.

Which approach is best for 10,000 employees?

Use a set-based SQL expression when the data is in SQL Server and the computation is simple. Use application code when workflow, external services, or complex application-specific behavior warrants it.

Part 5: Example Reflection

Comparing functions across four languages shows that language design affects more than syntax. C and C# emphasize declared types, while Python allows flexible runtime typing. SQL Server integrates functions with set-oriented data queries. The best solution depends on where the data lives and what processing is needed.
