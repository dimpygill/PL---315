Discussion Assignment: One Problem, Four Languages

Course: Programming Language Design (PL-315)
Topic: Functions in C, C#, Python, and Microsoft SQL Server
Total: 20 points

Learning Objectives

Compare function definitions, calls, parameters, return types, and typing systems across four languages. Explain how language design affects processing data.

Scenario: Employee Salary Bonus Calculator

A company wants to calculate a 10% bonus for employees. Create a function that accepts a salary, calculates the bonus, and returns the updated salary. For example, $6,000 becomes $6,600.

Part 1: Initial Discussion Post (12 points)

Question 1: Function Implementation (4 points)

Write a working function in C, C#, Python, and Microsoft SQL Server (scalar user-defined function). Show how to define and call each function and display the result.

Question 2: Language Design Comparison (4 points)

  1. How are parameters declared in each language?
  2. Is an explicit return type required?
  3. How do static and dynamic typing differ?
  4. How does calling a SQL scalar function differ from calling functions in C, C#, and Python?

Support your answers with examples from your code.

Question 3: Real-World Application (4 points)

Suppose 10,000 employees' salaries are stored in SQL Server. Explain how an application written in C, C#, or Python could calculate bonuses; how SQL could calculate them; and which approach you recommend, with justification.

Part 2: Peer Discussion (4 points)

Reply meaningfully to at least two classmates. Compare a language design choice, suggest a technical improvement, or ask and address a technical question. Replies consisting only of “I agree” or “Good job” do not earn full credit.

Part 3: Reflection (4 points)

In 3–5 sentences, explain what comparing these functions taught you about programming language design. Discuss at least one difference beyond syntax.
