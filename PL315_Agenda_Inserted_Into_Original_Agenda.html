Data Representation and Execution Across Four Languages

Imperative versus declarative computation

Agenda for the Coming Weeks

(Approximately 1–2 weeks, depending on class progress.)

Why are we revisiting C, Python, and C#?

We have already studied programming concepts using C, Python, and C#. We are not starting these languages again. We will build on that knowledge by learning SQL Server queries and indexing, then use familiar examples to compare language design decisions, abstraction, and execution strategies.

Upcoming Topics

  1. SQL Server Queries — Review and Practice: SELECT, FROM, WHERE; filtering records and expressing the desired result.
  2. SQL Server Indexing: What indexes do; table scans versus index seeks; why an index is not always selected.
  3. SQL Server Query Optimization: Query optimizer, logical request, physical execution plan.
  4. Linear Search — Review for Comparison: Revisit familiar C, Python, and C# examples; compare explicit search loops with SQL queries.
  5. Hash Tables and Dictionaries: Hash-based lookup, collision handling, capacity and resizing; C implementation, Python dict, and C# Dictionary.
  6. Programming Language Design Concepts: Static versus dynamic typing, data representation, memory management, abstraction, programmer responsibility.
  7. Imperative vs. Declarative Programming: How explicit loops specify HOW and SQL specifies WHAT; distinguish programmer instructions from optimizer-selected execution plans.
  8. Programming Language Design Trade-offs: Compare implementations and responsibilities across C, Python, C#, and SQL Server.

Student Activities

  1. Compare programming language design decisions across C, Python, C#, and SQL Server.
  2. Identify trade-offs associated with different implementations.
  3. Analyze how typing, memory management, abstraction, and execution strategies influence program behavior.

Expected Learning Outcomes

We will learn to distinguish imperative and declarative execution models, understand SQL indexing and query optimization, and evaluate programming-language design characteristics in relation to project requirements.

Learning outcomes

  • Explain data representation, abstraction, and procedural versus declarative execution.
  • Trace a linear search in C, Python, and C# and compare it with an SQL predicate.
  • Distinguish a language feature from a particular data structure or implementation.
  • Describe the difference between an SQL logical request and a physical execution plan.
